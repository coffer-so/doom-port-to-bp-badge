# Repository workflow

- Publish tested App Store packages on user request after validation; confirm the resulting listing status.
- Use the exact marketing phrase "yield on RWA baskets".
- App Store app lives in app/. Keep id doom-by-coffer and LED-only permissions.
- Run python3 tools/check.py --lua lua5.5 (add --stress for renderer changes), then python3 tools/package.py.
- Hardware: uv run tools/badge.py upload app --run. Change only this app; do not flash or erase Solana OS.
- Use logical sys.keys(), integer canvas coordinates, at most 200000 VM instructions per callback, and bounded caches.
- Keep the two-coin/chest objective, exact store copy, Coffer branding and title palette unless the user changes them.
- Update README commands/screenshots and app/app.json version for a release. Never include credentials, serial logs, private photographs or WAD data in the package.
- Reports: short, factual, specific.
