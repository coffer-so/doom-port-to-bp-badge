# Provenance

Original Doom: id Software. Doomgeneric: ozkl and contributors, based on the original Doom engine and Chocolate Doom. Existing file-level copyright and license notices remain unchanged.

The vendor/doomgeneric tree is exported from the exact public revision in UPSTREAMS.json, without upstream Git metadata/history or screenshot assets. No Solana OS firmware assets, game WADs, private reports, user photographs, credentials or session logs are included.

The Coffer project is a planned adaptation. This preparation snapshot contains no completed badge port. It must not be described as a running game or validated firmware.
