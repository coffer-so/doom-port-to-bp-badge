# Provenance

Original Doom: id Software. Doomgeneric: ozkl and contributors, based on Doom and Chocolate Doom. File-level notices in vendor/doomgeneric remain unchanged; the pinned revision is in UPSTREAMS.json.

The installable app/ package is a separately written, original Lua raycasting adaptation in the style of Doom. It does not execute Doomgeneric, parse WADs, or include original Doom levels, graphics, sounds or music. Its map, game pixel artwork and application source were created for this project and are GPL-2.0-or-later. The title-screen DOOM wordmark is a separately credited original logo; Coffer supplied its mark. Those logos are not covered by the code license; see app/credits.txt.

The title Doom describes the adaptation's inspiration; Coffer attribution identifies this adaptation, not authorship or ownership of the original Doom game.

No Solana OS firmware or its fonts/logos, photographs, credentials, badge settings or personal session logs are included in the upload package. Solana OS is an external dependency under its own license. Other researched engines are referenced in docs/research.md but are not copied into the application.
